# Contributing

Build, test, and conventions are documented once, in
[`AGENTS.md`](./AGENTS.md) — the same file this server reads and serves.
Start there.

## Issues

Found a bug, or something in the README/docs that doesn't match what the
server actually does? Open an issue.

## Pull requests

Keep it focused — one change, one PR. `npm test` and `npm run typecheck`
must pass; CI runs both across Linux, macOS, and Windows.

## Security

Don't open a public issue for a vulnerability — see
[SECURITY.md](./SECURITY.md).
